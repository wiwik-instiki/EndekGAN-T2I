# Data, code, and image-rights restrictions

This public-facing repository exports code and numerical summaries only. The curated Endek image dataset, copyrighted textile photos, expert-rated image panels, original evaluation image paths, pretrained model weights, checkpoints, private mappings, and full manuscripts are NOT distributed in this folder.

Before publishing:
- Confirm image rights and informed authorization where relevant; if rights are limited, supply access instructions rather than publishing copyrighted assets.
- Confirm software code ownership and coauthor permission. This export does NOT attach an open-source license.
- Review all notebooks/historical and scripts for personal/private path mentions and any embedded credentials. Code is supplied for provenance; some historical paths and configurations still refer to the original Windows environment.
- Cite external DF-GAN and StyleGAN2-ADA projects and follow their respective licenses. Their sources are not vendored. StyleGAN2-ADA is not a completed quantitative comparator in this final study.
- Follow the journal's policies for code/data availability and repository timing.
- The blinded expert-rater identity mapping must never be disclosed to evaluators.

The public numerical summary is insufficient for independently training the model from scratch; authorization to obtain the full raw dataset and pretrained models remains a separate prerequisite.
